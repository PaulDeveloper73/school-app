DPSI SCHOOL MANAGER — STATIC DASHBOARD UI

FILES
- index.html : dashboard markup and page metadata
- style.css  : complete responsive styling

HOW TO USE
1. Keep index.html and style.css in the same folder.
2. Open index.html in a modern browser, or copy the files into your web project.
3. Replace the sample profile, campus and student image URLs with your approved school images.
4. Update sample counts, notifications, fee figures, dates and academic-year details with live school data.
5. Add your JavaScript to handle the controls and connect the links to your application routes/API.

JAVASCRIPT HOOKS
- Buttons include data-action attributes, for example data-action="toggle-sidebar".
- Add/remove the class "is-open" on #sidebar to open/close the mobile navigation.
- Dashboard navigation links use #section-name placeholders.

NOTES
- No application JavaScript or backend logic is included, as requested.
- Google Fonts and the sample photos load from external URLs and require an internet connection.
- The figures and activity items are illustrative UI content, not live school records.
