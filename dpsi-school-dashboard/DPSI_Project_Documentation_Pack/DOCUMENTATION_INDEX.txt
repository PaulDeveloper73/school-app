CRITICAL STATUS
This package is a product and delivery specification. It does not implement or certify the product. The current application baseline is a browser-only front-end prototype using localStorage. Do not use it to store real student, guardian, medical, safeguarding, staff or financial information. Production use requires implementation, external provider setup, security/privacy/legal review, tested backup and restore, QA, department UAT and signed GO-001–GO-015 approval.
